Allow pop-ups for advanced security

Some security features, such as approving sensitive changes, open in a secure pop-up window served by Tide’s decentralised network. Your browser needs to allow pop-ups from this site for them to work.

    Is this safe?

    Yes. You’re only allowing pop-ups from one site, not the whole web. The pop-up is Tide’s secure enclave, where approvals are signed separately from the app.

    I allowed pop-ups but it still doesn’t work

    Reload the app. If you use a separate pop-up blocker extension, allow the site there too.
